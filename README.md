# Sistema-de-Gesti-n-y-Renta-de-Veh-culos
Aplicación de consola desarrollada en C# para gestionar una flota de vehículos destinada a servicios de renta.  El sistema permite registrar diferentes tipos de vehículos, consultar su información, buscar vehículos por código, visualizar vehículos según su estado y realizar diferentes operaciones relacionadas con la administración de la flota.
